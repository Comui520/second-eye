# 升级阶段一核心功能验证记录

状态：阶段一核心实现已落地；整个升级未完成，未合并、推送或发版。

## 已落地

- 应用采用无 import 副作用工厂；原 `python -m goodprice` 保持可用。
- 规格身份、整分金额、明确价／区间／询价／冲突／未知价裁决。
- 观察记录与人工报价分开保存；报价默认 7 天、支持撤销，证据过期不继续推荐。
- 搜索页起售价不提前过滤目标规格，品相分析和性价比使用所匹配规格的确价。
- 最低品相分不被未知评分绕过；有限搜索未见不冒充确定下架。
- 实验性 DOM／Schema.org 提取、商品证据展示、任务目标规格和待询价提醒。
- 单渠道失败不会被其他成功渠道遮蔽；未知投递结果不自动反复重试。
- 旧库幂等迁移、旧通知基线兼容；用户运行数据未用于开发测试。

## 设计裁决与修复范围

- 阶段一使用串行适配器复用 offer 阶段契约；移除旧的重复价格/通知私有实现，避免两条业务规则并存。
  代价：外部代码若调用旧私有方法需迁移，公开 run_task 入口保留。
- 删除任务保留商品和报价历史、清除任务关联，而不是删除用户历史。代价：会保留无法再调度的历史商品。
- 旧“详情失败继续按标价推荐／有限搜索三轮未见就确定下架”的测试按已批准语义更新，而非保留不可信行为。
- Docker 两次构建遇到官方 Debian HTTP CDN 502，改为官方 HTTPS 源并启用三次有限重试；签名验证未关闭。
  若 HTTPS 也不可达则仍明确构建失败，不做不安全回退。
