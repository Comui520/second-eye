# 分阶段执行与交互验证记录

本记录保存 `codex/offer-media-upgrade` 合入前的验证结果；验证阶段没有替换原服务或发布版本。后续版本发布信息见 [CHANGELOG](../../CHANGELOG.md)。

## 已接入的行为

- FastAPI 生命周期创建单个协调器，APScheduler 只提交信号；正式入口不再消费旧整任务队列。
- 搜索、详情、解析、媒体、模型与聚合分阶段推进；持久化游标、版本、租约、容量、请求预算和恢复状态。
- 同账号单页面导航、平台最小间隔和模型 RPM 分开限制；取消固定300秒整任务间隔。慢模型期间第二任务可推进抓取。
- 浏览器所属线程复用，隔离页面上下文；媒体和模型资源独立限制。内存压力临时降并发或缓派，保留保存配置。
- 独立通知 outbox 在发送前重新核验证据；成功渠道不重复，无法确定是否接受的投递不自动重发。
- 需求/视觉缓存绑定内容、提示词和模型配置；性价比分项独立缓存，不因动态批次成员变化重复收费；当前有效项在本地比较。
- 列表筛选/排序/加载范围与返回位置保留，设置分类单独保存，清除凭据需确认；运行时样式和HTMX随包提供。

## 审查与回归

阶段末由独立审查者只读检查整分支及新增生产接线；无 Critical、四项 Important、无其他 Minor。
四项均先用合成数据复现失败，再修复，未进行重复审查：

1. 评分完成后、聚合前人工报价改变：聚合事务复查评分价格上下文，按新价格重评。
2. 搜索标题变化但详情失败：追加失效状态，保留历史，停止旧推荐和未发送事件。
3. 渠道接受后响应连接断开：结果归为 uncertain；仅明确拒绝或连接尚未建立等安全失败自动重试。
4. 删除商品后 SQLite 复用编号：业务键和发送前核验包含平台、外部商品身份及规格，避免漏发新商品或误投旧事件。

对应 `tests/test_final_review.py`，同时覆盖旧消息尚未投递的编号复用情况。
其他回归包括：超额候选恢复、暂停后迟到结果、429 Retry-After、HTTP预算、配置变化、报价变化、慢模型价格过期刷新、
单独重评不通知、签名地址内容去重、旧图片字段兼容、卖家风险/缓存/拉黑、通知操作、资源检测、缓存损坏恢复和异常关机。

## 离线性能对照

可重现命令：

```sh
uv run --locked python scripts/benchmark_stages.py --rounds 3 --output output/benchmark
```

数据见 [原始记录](2026-10-27-pipeline-benchmark.json)。两种实现均处理相同30件确价合成商品、相同需求与评分输入，视觉关闭；
没有浏览器、真实网络、付费模型、真实账号或外部通知。导航/RPM使用压缩逻辑时钟；阶段时间为逻辑时间。
Python内存由 tracemalloc 记录，RSS仅采样当前Python进程，不含浏览器/FFmpeg子进程。
本机同时运行构建/回归，并非独占性能环境；三次样本的P95只是经验上界，不能当稳定尾延迟估计。

| 实现 | 冷/热 | 完整有效评分 | 模拟模型请求 | SQL次数 | 耗时中位数 / P95 |
| --- | --- | --- | --- | --- | --- |
| 串行适配层 | 冷 | 30/30 | 31 | 1387 | 6.29s / 7.81s |
| 串行适配层 | 热 | 30/30 | 0 | 757 | 2.89s / 7.00s |
| 分阶段协调器 | 冷 | 30/30 | 38 | 9308–9388 | 31.62s / 34.41s |
| 分阶段协调器 | 热 | 30/30 | 0 | 8769–8846 | 31.89s / 33.54s |

协调器的持久化、校验与恢复有明显纯本地开销；小批及时评分增加冷轮请求数，不能宣称所有工作负载都更快。
已验证的收益是慢模型与后续抓取可以重叠、浏览器复用、取消固定300秒任务间隔、列表查询批量化、热轮重复模型请求归零。
后续优化空间是减少活跃轮次的状态轮询SQL，不能通过降低输入覆盖或突破平台间隔来美化指标。

## 执行决定与限制

- 使用主线程持续实现、阶段末一次独立审查；导航和设置先于生产接线完成。代价是必须整体复验，不能以组件测试冒充接线完成。
- 本轮仅价格过期、已采集内容身份不变时刷新价格并复用原媒体；不声称媒体重新采集。代价是同地址媒体在该轮内变化，可能到下一轮普通采集才检测到。
- 内容缓存绑定提示词/需求/模型等语义输入；磁盘大小、FFmpeg线程等运行参数不单独触发付费重评。代价是遗漏语义输入会错误复用，因此专门覆盖提示词、内容和配置失效测试。
- 保留旧 CrawlService/TaskQueue 给导入调用者与回归使用，正式入口只运行协调器。代价是旧导入路径仍需维护。
- 拒绝把来源不明、共享样品或未核验的价格/品相当作确定结果；真实闲鱼规格控件和视频结构仍待脱敏样本验证，功能保持实验性。
- 本次本机Windows和Linux容器验证不代替macOS/ARM验收；同一数据目录只允许一个应用进程。
- 审查者未独立判定性能、部署和全量测试，由本记录的实际执行结果负责；批准的价格刷新与单进程边界继续保留，代价如上。
