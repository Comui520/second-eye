# 闲鱼盯价助手 MVP — 设计文档

## 目标

面向个人用户的本地 Web 工具（开源、MIT）：用户建立「关键词 + 最高价 + 品相要求」的监控任务，
程序定时抓取闲鱼新上架商品，价格初筛后交给多模态大模型看图判断品相，命中则站内记录并通过
Server酱推送微信提醒。

## 非目标（MVP 范围外）

- 单品盯价（收藏单个链接盯降价/下架）
- 转转等其它平台（通过适配器协议后续追加）
- 多账号、多用户、云端部署
- 移动端界面

## 架构

单进程一体化：FastAPI 提供 Web 界面与 JSON API，APScheduler 在进程内调度抓取任务，
SQLite 单文件存储。模块边界：

- `crawler/`：平台适配器协议 + 闲鱼 Playwright 适配器 + HTML 解析（BeautifulSoup）
- `analysis/`：OpenAI 兼容 LLM 客户端，多模态品相分析，输出结构化结论
- `notify/`：通知通道协议，内置日志通道与 Server酱
- `services/`：设置服务（环境变量默认值 + 数据库覆盖）、任务服务、爬取流水线
- `db/`：SQLAlchemy 模型（监控任务、商品、价格快照、通知记录、设置项）
- `web/`：Jinja2 + HTMX + Tailwind（CDN）服务端渲染页面与路由

## 核心流程

1. 用户粘贴闲鱼 Cookie（浏览器登录 goofish.com 后从开发者工具复制）
2. 定时任务按随机抖动间隔加载搜索页，解析新上架商品
3. 价格初筛 + 按商品 ID 去重
4. 对带图商品调用 LLM，返回品相分 1–10、瑕疵列表、是否推荐、一句话理由
5. 品相分低于任务阈值则不通知；命中记录入库，同一商品只通知一次
6. 无 LLM Key 或 LLM 调用失败时降级为仅价格命中

## 数据模型

- `watch_tasks`：关键词、最高价、品相要求、最低品相分、间隔、启停、最近运行状态
- `listings`：平台 + 外部 ID 唯一约束，价格、图片、卖家、地点、品相结论、通知时间
- `price_snapshots`：商品每次价格变化留痕，用于走势展示
- `notifications`：通知发送记录（通道、状态、详情）
- `app_settings`：键值设置，覆盖 `.env` 默认值

## 合规与安全

- 使用用户本人账号的登录态，单账号限速 + 请求抖动
- README 明示平台条款与法律风险，工具仅供个人学习研究
- 任何凭据不入库到 git（`.env` 与 `data/` 均被忽略）
