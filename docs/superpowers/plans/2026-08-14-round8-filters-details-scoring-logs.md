# 第八轮：筛选增强 + 详情页 + 评分修复 + 日志与体验优化

## 目标

- 任务新增「价格下限」与「排除词」，过滤超低价配件噪音。
- 新增任务详情页（参数可直接改 + 运行统计）与商品详情页（原文/LLM 结论/评分/价格走势/跳转/重新分析）。
- 商品图规则过滤：只收真图、主图优先。
- 评分六项修复：品相缺失半值、卖家未知半值、降价加成、存量全量重算、两条提示词优化。
- 控制台分步日志 + 滚动文件日志；命中列表"加载更多"；操作后保留筛选并带 toast。

## 关键实现

### 数据与过滤
- `WatchTask` 增列 `min_price`(Float 默认 0) 与 `exclude_words`(Text 默认 "")；幂等迁移。
- 抓取过滤：低于 `min_price`（>0）或高于 `max_price` 跳过；排除词按空白/中英文逗号拆分，标题命中任一即跳过（不入库）。

### 图片
- 搜索卡片图只收 `bao/uploaded` 真图；详情图按 `xy_item` 主图优先排序、最多 8 张。

### 评分与提示词
- 品相缺失（视觉开启）按半值 15；卖家未知/无数据按半值（与中同档）。
- 降价加成：较首见降幅 ≥8% 加 1 档、≥20% 加 2 档，折算进性价比（缺失按 5 分基准），总分封顶 100。
- `backfill_satisfaction` 全量重算（启动与保存设置时）。
- 品相提示词改为纯品相判断（明确不因价格改变品相分）；批量性价比每行带买家需求。

### 页面
- 任务详情 `/tasks/{id}`：参数编辑表单（含新字段）+ 命中/通知/运行统计 + 最近命中 + 操作；`/tasks/{id}/edit` 重定向。
- 商品详情 `/listings/{id}`：图片网格、徽标、价格快照走势（表格）、描述原文、需求/品相/性价比结论及失败原因、卖家信息、变体区间、通知历史、跳转/重新分析/拉黑/删除。
- 重新分析 `POST /listings/{id}/reanalyze`：后台线程重抓详情并重跑分析，不发通知。
- 命中列表 `offset` 分页 + "加载更多"（HTMX 局部追加）；拉黑/删除等操作保留 `task_id/sort/show` 并带 toast。

### 日志
- `main.py` 日志格式带时间与模块，新增 `data/logs/app.log` 滚动文件（5MB×3）。
- `crawl_service` 分步 INFO 日志：搜索命中数、跳过原因、新品/重评、需求/品相结论、批量性价比结果、通知发送、下架标记。

## 测试计划
- 单元：min_price/exclude_words 过滤；卡片占位图过滤与主图排序；评分六项；批量行带需求；重新分析不通知。
- 接口：任务详情页、商品详情页、重新分析后台执行、offset 分页、操作保留筛选。
- 回归：全量 pytest；真实库冒烟启动 + 迁移。

## 假设与默认
- 排除词只匹配标题；命中即不入库。
- 手动"重新分析"不发通知。
- 详情页走势用表格，不引入图表库。
- 日志默认 INFO，控制台 + 滚动文件，前端不展示日志。
